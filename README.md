# Organización Camanchaca    

¡Bienvenido al espacio de trabajo de Camanchaca!

### 📌 Pautas de Trabajo
- **Estructura de ramas:** Todos los repositorios nacen con la rama `main` y `develop`.
- **Estándar de entregas:** Las contribuciones deben realizarse mediante **Pull Requests** dirigidos a la rama `develop`.
- **Pasos a producción:** Los pasos a producción se realizan desde la rama `develop` mediante un **Pull Request** dirigido a la rama `main`.
- **Archivos base:** Cada repositorio se inicializa automáticamente con `.gitignore`, `.env.example` y un `README.md` base.

### 🛠️ Automatizaciones
Este repositorio contiene los flujos de **GitHub Actions** encargados de aprovisionar y estandarizar automáticamente los nuevos proyectos creados en la organización.
